# E2E测试 - 我的饭小程序

本目录包含微信小程序的端到端测试脚本。

## 前置条件

1. **微信开发者工具**
   - 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
   - 打开开发者工具，导入 `miniprogram/` 目录
   - 确保模拟器已启动

2. **后端服务**
   ```bash
   cd backend
   python main.py
   ```
   确保服务运行在 http://localhost:8000

3. **测试数据**
   ```bash
   cd crawler
   python main.py --import
   ```
   导入示例菜品数据

## 安装依赖

```bash
cd e2e
npm install
```

## 运行测试

### 方式1: 命令行运行

```bash
cd e2e
npm test
```

### 方式2: 微信开发者工具内置测试

1. 打开微信开发者工具
2. 点击"测试"面板
3. 选择"自动化测试"
4. 运行测试用例

## 测试场景

| 场景 | 描述 | 测试点 |
|------|------|--------|
| 场景1 | 浏览菜品并查看详情 | 首页加载、分类筛选、详情页 |
| 场景2 | 添加菜品到购物车 | 添加功能、重复提示、数量更新 |
| 场景3 | 查看和管理购物车 | 列表显示、删除、清空 |
| 场景4 | 创建订单并分享 | 订单创建、分享功能 |
| 场景5 | 打开分享链接 | 分享码解析、协作加菜 |
| 场景6 | 边界情况 | 空购物车、无效分享码 |

## 测试脚本说明

### basic-flow.test.js

基本流程测试脚本，包含以下测试用例：

- **场景1**: 浏览菜品并查看详情
  - 首页加载正常
  - 分类筛选功能
  - 菜品详情页

- **场景2**: 添加菜品到购物车
  - 从首页添加菜品
  - 重复添加提示

- **场景3**: 查看和管理购物车
  - 购物车页面显示
  - 删除菜品
  - 清空购物车

- **场景4**: 创建订单并分享
  - 创建订单

- **场景5**: 打开分享链接
  - 通过分享码打开订单
  - 协作加菜功能

- **场景6**: 边界情况
  - 空购物车分享提示
  - 无效分享码

## 常见问题

### Q: 连接微信开发者工具失败

**A**: 确保：
- 微信开发者工具已启动
- 已打开小程序项目
- 已启用"自动化测试"功能

### Q: 测试超时

**A**: 检查：
- 后端服务是否正常运行
- 网络连接是否正常
- 测试数据是否已导入

### Q: 元素找不到

**A**: 可能原因：
- 页面未完全加载
- CSS选择器不正确
- 页面结构已更改
