## 场景1: 浏览菜品并查看详情

### 1.1 首页加载
- [ ] 打开小程序，首页正常加载
- [ ] 显示"当季推荐"区域
- [ ] 显示菜品分类标签（全部、凉菜、热菜、汤羹、主食、甜品、饮品）
- [ ] 菜品列表正常显示（图片、名称、价格、描述）
- [ ] 购物车图标显示在右下角

### 1.2 分类筛选
- [ ] 点击"热菜"标签，列表只显示热菜
- [ ] 点击"凉菜"标签，列表只显示凉菜
- [ ] 点击"全部"标签，显示所有菜品
- [ ] 当前选中的标签高亮显示

### 1.3 菜品详情
- [ ] 点击菜品卡片，进入详情页
- [ ] 显示菜品大图
- [ ] 显示菜品名称
- [ ] 显示价格（¥格式）
- [ ] 显示菜品描述
- [ ] 显示分类标签（如：热菜）
- [ ] 显示季节标签（如：春）
- [ ] 显示难度等级（简单/中等/困难）
- [ ] 显示烹饪时间（分钟）
