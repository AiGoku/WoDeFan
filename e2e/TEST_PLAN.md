## 测试场景

### 场景1: 浏览菜品并查看详情

**目标**: 验证首页加载、分类筛选、菜品详情展示

**步骤**:
1. 打开小程序首页
2. 验证页面加载成功，显示"当季推荐"
3. 点击"热菜"分类标签
4. 验证列表只显示热菜分类
5. 点击第一个菜品卡片
6. 验证详情页显示：
   - 菜品图片
   - 菜品名称
   - 价格
   - 描述
   - 分类标签
   - 季节标签
   - 难度等级
   - 烹饪时间
   - 辣度
   - 食材列表
7. 点击返回按钮回到首页

**预期结果**:
- ✅ 首页正常加载，显示菜品列表
- ✅ 分类筛选功能正常
- ✅ 菜品详情信息完整

---

### 场景2: 添加菜品到购物车

**目标**: 验证从首页和详情页添加菜品到购物车

**步骤**:
1. 在首页点击第一个菜品的"+"按钮
2. 验证Toast提示"已加入"
3. 验证购物车图标显示数量"1"
4. 点击第二个菜品的"+"按钮
5. 验证购物车图标显示数量"2"
6. 点击第一个菜品进入详情页
7. 点击"加入菜单"按钮
8. 验证Toast提示"已在菜单中"（重复添加）
9. 返回首页

**预期结果**:
- ✅ 添加成功提示正确
- ✅ 购物车数量实时更新
- ✅ 重复添加有提示

**目标**: 验证购物车页面功能

**预期结果**:
- ✅ 购物车列表正确显示
- ✅ 总价计算准确
- ✅ 删除功能正常
- ✅ 清空功能正常

## 自动化测试脚本

### 使用miniprogram-automator

```javascript
// e2e/basic-flow.test.js
const automator = require('miniprogram-automator');

describe('基本流程测试', () => {
  let miniProgram;

  beforeAll(async () => {
    miniProgram = await automator.connect({
      projectPath: './miniprogram'
    });
  });

  afterAll(async () => {
    await miniProgram.close();
  });

  test('首页加载', async () => {
    const page = await miniProgram.reLaunch('/pages/index/index');
    await page.waitFor('.dish-list');
    const dishes = await page.$$('.dish-card');
    expect(dishes.length).toBeGreaterThan(0);
  });

  test('添加菜品到购物车', async () => {
    const addBtn = await page.$('.add-btn');
    await addBtn.click();
    const toast = await page.waitFor('.wx-toast');
    expect(await toast.text()).toContain('已加入');
  });
});
```

### 运行测试

```bash
# 安装依赖
npm install miniprogram-automator --save-dev

# 运行E2E测试
npm run test:e2e
```
